# Client Fulfillment Playbook

Revenue only matters if Transcenlutions delivers useful work. These first paid
offers have to create clear buyer artifacts, not vague motivation.

## Tay Command Starter Map

Price: `$97`

Buyer outcome: one passive-income offer direction, one simple workflow, and one
next action the buyer can execute within 24 hours.

Delivery artifacts:

- one-page offer map
- buyer outcome statement
- first workflow checklist
- governed next-step list

Delivery flow:

1. Confirm buyer goal and current blocker.
2. Name the first sellable outcome.
3. Map the smallest delivery workflow.
4. Close with one action the buyer can take within 24 hours.

Quality standard: the buyer should leave knowing exactly what they sell, who it
helps, why it matters, and what to do next.

## Operator Build Sprint

Price: `$497`

Buyer outcome: a sellable offer direction, operating plan, and seven-day
execution agenda.

Delivery artifacts:

- offer positioning brief
- lead-flow or content plan
- automation boundary map
- seven-day execution agenda

Delivery flow:

1. Clarify offer, buyer, and current assets.
2. Choose the strongest first lead or content path.
3. Map the automation boundary before any tooling.
4. Build a seven-day execution agenda with one visible daily output.

Quality standard: the buyer should leave with a focused system they can run
immediately without needing another strategy reset.

## Care Rules

- Every paid offer must have a clear buyer outcome before payment is requested.
- Every session closes with a visible artifact the buyer can use.
- Tay should prepare the work, but the operator stays responsible for quality.
- Follow-up should ask what moved, what blocked, and what needs tightening next.
