# Tay Engine Box 4: Founder Operating System

Box 4 gives Tay a founder command layer so Transcenlutions can keep shipping
without losing focus.

## Purpose

The founder is still the bottleneck. Tay now protects the current build phase,
routes new ideas into clear lanes, keeps revenue-readiness visible, and creates
a spouse-visible focus summary.

## Founder Command Loop

```text
founder request
-> Tay detects focus intent
-> governance classifies route_focus as allowed
-> Tay routes the work through NOW / NEXT / LATER / PARKED
-> visible result appears
-> Founder Command Artifact is created
-> session log records the truth
-> next step keeps the current box moving
```

## Daily Execution

- keep Box 4 as the only build target
- choose three priorities before adding new ideas
- complete one revenue-readiness action
- record one win and one stall before ending the work session

## Weekly Review

Tay prepares a weekly review around:

- what shipped
- what stalled and why
- what moved revenue readiness forward
- what created context switching
- what the next box should be

## Anti-Distraction Rule

When a request tries to jump into future work, Tay responds with:

```text
Current box incomplete. Add to backlog or continue current phase?
```

Future ideas are not deleted. They are routed into `PARKED` until the current
box is complete.

## Focus Lanes

- `NOW` - active Box 4 work only
- `NEXT` - prepared after current box is stable
- `LATER` - valid future work with no action today
- `PARKED` - strong ideas intentionally held back

## Family Alignment

Box 4 includes a short spouse-visible status:

- current focus: Box 4
- expected finish: 2 weeks
- completed: Box 1-3
- money readiness: prepared, awaiting Stripe/email setup

## What Box 4 Does Not Build

- no dating app
- no Crowne Legacy build
- no advanced agent council
- no marketplace
- no full autonomy
- no new payment collection behavior

## Definition Of Done

- Founder Command panel is visible in the command room.
- Focus requests map to `manage_focus` / `route_focus`.
- `route_focus` is governed as an allowed local action.
- Daily priorities, weekly review, backlog, and family summary are visible.
- Expansion requests are parked instead of started.
- lint, typecheck, smoke, and build pass.
