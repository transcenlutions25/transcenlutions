# Tay Engine Box 6: Private Alpha Readiness

## Goal

Make Tay genuinely useful for the first five private alpha testers.

The private alpha promise is:

```text
Tay helps overwhelmed builders stop spinning and start executing.
```

## Scope

Box 6 focuses only on:

- clarity
- usefulness
- onboarding
- first-session success
- reduced overwhelm
- repeat-use signals
- tester feedback

It does not start the dating app, Crowne Legacy, new agents, community systems,
marketplace work, or advanced automation.

## First-Time User Experience

The first screen now asks:

```text
What are you trying to improve or build?
```

Supported starting paths:

- Business
- Focus & Productivity
- Revenue
- Planning
- Content
- Personal Growth

Each path routes through Tay chat as a governed local action. Tay responds with
a result artifact and a next step instead of leaving the tester wondering what
to do.

## First 10-Minute Win

The alpha flow is built around fast relief:

- overwhelmed -> one clear next step
- too many ideas -> choose what to do first
- stuck -> simple action plan
- disorganized -> NOW / NEXT / LATER / PARKED structure

The goal is not a huge plan. The goal is that a tester feels more clear,
organized, or motivated within the first session.

## Alpha Readiness Panel

The command room shows:

- current stage: Private Alpha Preparation
- onboarding clarity
- usefulness
- tester readiness
- repeat-use likelihood
- launch stage

These are session-level readiness signals, not a database-backed customer
system.

## Founders Circle

The lightweight tester offer is:

- first 5 testers
- free for 6 months
- feedback after real sessions

Tay can prepare the tester invite language, but it does not send invites or add
external accounts from the app.

## Feedback Boundaries

Private alpha feedback can influence:

- wording
- clarity
- onboarding
- help text
- UX friction
- minor layout improvements

Private alpha feedback cannot directly change:

- mission
- values
- governance rules
- payment handling
- privacy
- security
- legal copy
- user data handling
- memory architecture

## Acceptance Checks

- A new tester sees the Tay promise immediately.
- A new tester can choose one starting path without explanation from the founder.
- `I have too many ideas and need help choosing what to do first.` routes to a
  private alpha result.
- `Prepare Founders Circle tester invite` returns the tester support flow.
- `Show private alpha readiness` shows the current stage and readiness artifact.
- All private alpha work remains session-only and governed locally.
