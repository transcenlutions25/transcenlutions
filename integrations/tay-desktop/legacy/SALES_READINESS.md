# Transcenlutions sales readiness

This file is the source of truth for what may be sold or promised.

## Ready to sell now

- Discovery and workflow design sessions led by Transcenlutions.
- A manually delivered revenue-recovery pilot for one service business.
- Tay Command local chat using the installed Ollama model.
- Tay Command project selection, local conversation history, text-file references, copying, export, microphone dictation where supported, Mac text-to-speech, and the Venture Foundry capture workflow.
- Research and voice services only when the customer's approved provider account, key, quota, and consent are available and the request completes successfully.

## Pilot only

- Quote and lead follow-up workflows. Sell the outcome as a reviewed pilot with defined channels, hours, templates, and reporting. Do not promise automatic booking, guaranteed revenue, or unattended customer messaging.
- Tay Command online model connections. State the provider, model, data sent, limits, and whether billing is enabled.
- Unity and Unreal project launch assistance. Tay can open installed tools; this is not a promise of a finished game or console build.
- ElevenLabs voice playback. It requires a customer-owned voice, key, voice ID, quota, and successful API request.

## Do not sell yet

- Autonomous desktop control, browser/plugin control, or unsupervised agents.
- Reliable wake-word identity detection, offline speech recognition, microphone conversation that runs unattended, or lip-sync avatar animation.
- Native Xbox Series X|S deployment, certification, store publishing, multiplayer services, or Microsoft account integration.
- Automatic access to ChatGPT, Claude, Perplexity, ElevenLabs, cloud projects, subscriptions, memories, or prior conversations.
- Guaranteed revenue, lead conversion, response time, uptime, accuracy, compliance, or customer outcomes.

## Promise rule

Before creating an offer, check this file and the current test evidence. If a feature is not marked Ready to sell now, describe it as a pilot, demo, or planned capability. Name the exact deliverables, exclusions, customer responsibilities, dependencies, review points, price, and success measures. Never imply that a subscription includes API access. Never claim a tool, integration, build, or result worked without a recorded successful test.

The current revenue path is the Tay Revenue Recovery Pilot. Islands, Polsia-style worlds, Crowne Shards, always-on agents, user-created agent plans, and Tay self-building are roadmap concepts until the Revenue gate in REVENUE_PATH.md is met.
